CORS Security Setup

For security, Compust rejects requests from unknown extension origins. After loading this extension, ensure your backend .env contains this extension's origin:

COMPUST_EXTENSION_ORIGINS=chrome-extension://<EXTENSION_ID>,moz-extension://compust-capture@compust.ma

In Chrome: find the generated ID at chrome://extensions.
In Firefox: the ID is fixed to moz-extension://compust-capture@compust.ma.
